Actions
Nový secret SECRET.CREATE

Vytvori secret + prvni version.

Enabled: required metadata/value valid and stableName available · Confirm: NONE

Zobrazit SECRET.REVEAL

Reveal plaintext active/selected version.

Enabled: secret exists and version revealable · Confirm: NONE

Kopírovat SECRET.COPY

Kopiruje revealovanou hodnotu.

Enabled: plaintext currently revealed · Confirm: NONE

Nová verze SECRET.VERSION_CREATE

Vytvori immutable new secret version.

Enabled: secret mutable metadata exists and value valid · Confirm: NONE

Aktivovat verzi SECRET.VERSION_ACTIVATE

Atomicky prepnuti active version s invalidaci dependent state dle contractu.

Enabled: selected version eligible/current state valid · Confirm: NONE

Rotovat SECRET.ROTATE

Vytvori/aktivuje novou hodnotu podle rotation policy.

Enabled: rotation permitted · Confirm: NONE

Připojit SECRET.BIND

Vytvori exact binding source revision -> secret/version/purpose.

Enabled: source/revision/purpose exact and compatible · Confirm: NONE

Odpojit SECRET.UNBIND

Retiruje exact binding po impact validation.

Enabled: binding removable · Confirm: IMPACT_PREVIEW

Smazat SECRET.DELETE

Lifecycle delete pouze pokud contract dovoluje; system-reserved key nelze obecnym CRUD smazat.

Enabled: delete eligible · Confirm: EXPLICIT_CONFIRM

Exportovat SECRET.EXPORT

Export selected item/version podle contractu.

Enabled: exportable value/metadata selected · Confirm: NONE

Test resolve SECRET.TEST_RESOLVE

Otestuje exact binding resolution bez zmeny consumer state.

Enabled: binding active/current · Confirm: NONE
