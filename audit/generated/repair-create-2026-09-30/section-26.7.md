`POST /generation/jobs` přijímá `clientRequestId`, kind, objective, attachments a target reference. Stejný ID a shodný request digest vrací existující job; rozdílný digest vrací conflict.

`POST /generation/jobs/:id/approve-spec` vyžaduje exact `revisionId`, `digest` a current capability snapshot digest. Approval se provede v jedné transakci s execution authority a enqueue planneru.

`POST /generation/jobs/:id/blockers/:blockerId/resolve` validuje resolution proti blocker input schema a přijímá credential pouze přes Secret/credential reference. Resume vyžaduje exact latest checkpoint digest.

Workspace, model-call, validation a activation endpointy jsou read-only evidence surfaces, pokud jejich konkrétní operace není uvedena. OWNER nemůže ručně označit gate PASS nebo přímo přepnout lifecycle.

Job-scoped browser endpointy jsou convenience aliases nad `/browser-sessions`. Vracejí stejné session ID, control epoch, preview protocol a audit jako centrální chat nebo agentní browser call; nevytvářejí generation-only browser implementaci.
