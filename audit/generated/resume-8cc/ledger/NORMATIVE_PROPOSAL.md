### Proposed §12.56 — frozen side-effect producer and source-phase publication

Technical specialization of §§12.51.1,12.54,25.16,49.4,49.8–49.11,51.2,51.6,51.12,51.31. It changes no product permission, source-job terminal requirement, execution approval or cryptographic mechanism. It does not close other missing required producer families.

`database/generation-side-effect-producer.sql` implements a server-owned additive side-effect ledger. Generated code, model proposals and HTTP callers cannot write ledger/context/archive/authority tables or nominate a compiled classifier. Scope, target, immutable request, source phase and frozen classifier identity cannot change. Each immutable attempt has exactly one matching **canonical transactional_outbox SIDE_EFFECT_DISPATCH** row, with deferred exact composite references in both directions; other notifications cannot dispatch. All source/effect reads and producer writes remain under parent/phase/current-state locks through transaction commit.

A producer T1 atomically writes intent, immutable attempt, singleton lifecycle, immutable pre-checkpoint, exact domain-event and canonical dispatch authority. The future network worker requires separate fresh lease/incarnation/epoch/cancellation/deadline/concurrency and phase guard immediately before external dispatch. A checkpoint or outbox alone does not prove that guard or authorize dispatch.

Raw attempt evidence is immutable exact bytes with server-stamped fence/incarnation/observation time. Its next sequence is allocated from the locked singleton `last_evidence_sequence`; no MAX allocation. Deferred constraints enforce unique positive keys, exact count equal watermark and no key above watermark, which together prove the complete contiguous range. Actual immutable bytes, original producer identity and current attempt join remain authoritative.

Compiled classification binds `(classifierId, exactImplementationDigest)` to retained actual source bytes. The first declared CAS_READ_BACK_V1 profile invokes the fixed compiled SQL function only after its actual source bytes match the immutable archive. Its input mask is exactly `contracts/generation/cas-observation.schema.json`: seven fields, no extras, string digests/key/counters, UUID-or-null applied identity. Duplicate raw JSON keys or invalid UTF-8/JSON reject before classification. It classifies actual declared CAS readback, not arbitrary provider effects. Unsupported classifier/policy remains a specific blocker.

Known classification, immutable post-checkpoint, exact domain event and continuation outbox are one transaction. Deferred crossrow checks read final database rows, never historical queued trigger NEW tuples. Byte-identical retained result/publication replay returns its original bytes/identity; any differing bytes, source identity, target or retained selector produces a replay conflict. No terminal attempt/evidence is rewritten.

A checkpoint is exact server-compiled `contracts/generation/side-effect-checkpoint.schema.json` bytes. It includes current parent/state/version, incarnation/fence, monotonic sequence, approved revision/specification/plan, graph/binding/budget snapshot references, activation, completed steps/event watermark, actual pending-effect set, provider handles/cursors, workspace/browser references, cancellation and deadline. References carry exact record identity, content digest and schema identity/digest and require available archived bytes. Context/semantic source hydration remains mandatory; existence of a digest or synthetically declared record does not certify graph/binding/budget authority. No caller-supplied empty context or source-validity flag replaces them.

An active execution phase is a separate server row from its immutable completed failed-source snapshot. The phase begins against current rooted frozen plan/spec, actual active phase identity and server-captured fence/incarnation/epoch. Publishing a failed snapshot requires known side-effect outcomes and the available exact native KnownTechnicalFailureResult. The first concrete failure producer observes a genuine monotonic source fence advance, derives FENCING_TOKEN_STALE, publishes the immutable result and constructs the failed native snapshot; no caller-failed/valid/expired declaration is accepted as this predicate. Other error predicates require their own exact producers.

The native projection derives unchanged operation/attempt/current-state/evidence masks from actual ledger rows and exact frozen plan/observation schema; it emits canonical compact bytes and preserves their actual hashes. Re-publication verifies all original bytes and joins; it does not swallow conflict with ON CONFLICT DO NOTHING. A phase seal compares all registered ledger operations with all native physical operations, stores their frozen attempt/evidence identities/digests and prevents later producer/source mutation. Missing registration or a bypassed authority dispatch is never certified by a row count.

Remaining required audit, reconciliation/OWNER/manual/compensation/higher-attempt, native source hydration, trusted installation and additional failure predicate obligations remain blocking according to INTEGRATION.md. These are A/B design and fixture requirements, not silently deferred to production acceptance.
