# KájovoCML NG — Brand & UI identity

## Název
Kanonický název je **KájovoCML NG**. Hlavní lockup používá právě tuto podobu názvu.

## Logo a navigační ekosystém
Základ tvoří kompaktní monogram K v tmavém runtime jádru s tyrkysovou control-plane kružnicí. Navigační varianta má přesně **17 vláken**, jedno pro každou kanonickou navigační sekci odvozenou z UI registry. Aktivní segment určuje vybranou sekci a rotační pohyb mění aktivní sekci bez změny pořadí registry.

## Design tokeny
- primární font: Montserrat; fallback Inter, SF Pro Text, Segoe UI, sans-serif
- radius: 6 px
- primary teal: `#007f7a`, dark `#006966`, soft `#e8f6f5`
- ink `#18212d`, canvas `#f4f6f8`, sidebar `#111923`
- success `#1e9b55`, warning `#e49a12`, danger `#de3e35`
- motion: 120–180 ms, vždy reduced-motion safe

Logo zůstává čitelné i bez vláken pro favicon, login, sidebar a exportovanou evidenci.
