This is one grouped format decision, not approval requests for individual fields. Routine parser corrections and fail-closed diagnostics remain technical work. If a proposed profile fails a mandatory consumer, complete that profile or introduce the smallest explicitly named additional profile; do not silently drop the capability. A consumer declares supported `(type, variant)` pairs, purpose/target and security policy and rejects unsupported variants as `SECRET_VARIANT_UNSUPPORTED`. Global permissive algorithm callbacks in synthetic fixtures are not consumer security policies.

## Import, storage, reveal and activation

Current effective create masks still use the existing typed `value` representation. The proposed discriminators are not transparently substituted into that request and must not be guessed from content. Activation needs a normative versioned import mask, exact conversion table to the persisted Secret version, immutable original-byte representation, explicit read/use hydration and adapter declarations. Current candidate tests exercise parsing and reference storage only; they do not close that transition or its actual SQL/consumer handoffs.

Create/import responses and their events expose receipts and metadata, never automatically echo sensitive values. This protection does **not** repeal explicit OWNER reveal in §8.5/§8.6.1/§8.8 or their existing authorized business use. Reveal keeps its own authorization, purpose, audit and transport contract. Synthetic audit evidence never exercises live accounts and never publishes secret values.

Mandatory before generation: effective approved formats and conversion/consumer masks for required types, exact error predicates and persisted authority/lineage. Reference-verifiable now: strict parsing, exact-byte preservation, unsupported-profile rejection and synthetic relation checks. Future implementation acceptance: real vault encryption/key management, database isolation, adapter authentication and browser account postconditions. No owner format has been marked VERIFIED by these tests.
